# Sistema de Biblioteca

Sistema web desarrollado con Python, Flask y SQLite.

## Descripción

El proyecto permite gestionar libros y préstamos de una biblioteca.

## Funcionalidades

- Registrar libros.
- Visualizar libros.
- Eliminar libros.
- Registrar préstamos.
- Visualizar préstamos.
- Eliminar préstamos.
- Relacionar préstamos con libros.

## Tecnologías

- Python
- Flask
- SQLite
- HTML
- Bootstrap
- Git
- GitHub
